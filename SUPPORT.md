# Get involved

Start with the [three action experiment](https://automatron-workflows.github.io/hardwire/experiment.html).
Run sign in, invoice payment and settings. Change an input and inspect what was
blocked. No owned app or API key is needed.

Use [Discussions](https://github.com/Automatron-workflows/hardwire/discussions) for
questions, ideas and sharing what you tried. Include the scenario, browser or
Node version, whether you finished without help and what was confusing.

Use [Issues](https://github.com/Automatron-workflows/hardwire/issues) for a
reproducible defect or agreed work. The experiment feedback form accepts both
successful runs and problems. Keep records synthetic and small.

The [good first issues](https://github.com/Automatron-workflows/hardwire/labels/good%20first%20issue)
have a concrete scope and verification command. Comment on one before starting
to avoid duplicate work. Read [CONTRIBUTING.md](CONTRIBUTING.md) for setup and
[the community guidelines](CODE_OF_CONDUCT.md) for participation.
