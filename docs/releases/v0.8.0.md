# Hardwire 0.8.0

Agentic actions. Without the clicks.

The cinematic experiment covers sign in, invoice payment and settings. This
release adds the next developer step: bring a saved form, infer a draft contract,
check valid and invalid inputs, and produce an MCP tool description.

## Run the three actions

```sh
npx --yes --ignore-scripts --package=https://github.com/Automatron-workflows/hardwire/releases/download/v0.8.0/hardwire-0.8.0.tgz hardwire-experiment
```

## Bring one form

```sh
npx --yes --ignore-scripts --package=https://github.com/Automatron-workflows/hardwire/releases/download/v0.8.0/hardwire-0.8.0.tgz hardwire-form
```

Both commands require Node 22 or newer. The bundled form is the email preference
from the third scene. It accepts `false`, rejects `"false"` and produces the
`preferences` tool description. Add `--json` for the full result.

[Try the visual journey](https://automatron-workflows.github.io/hardwire/experiment.html)
or [use your own saved form](https://github.com/Automatron-workflows/hardwire/blob/v0.8.0/docs/FORM-EXPERIMENT.md).

The uploaded package is downloaded, checksummed and installed in a fresh consumer
project by the release workflow, which publishes only after verification succeeds.
Existing 0.7.x assets remain available.

Experimental scope: sign in and payment use fixed local fixtures. No accounts
connect or money moves. The form command never calls its endpoint. Inference does
not establish actual effects, reversibility or authorization. npm and MCP Registry
publication remain pending authenticated publisher and namespace verification.
