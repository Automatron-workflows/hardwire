# Hardwire 0.7.1

Agentic actions. Without the clicks.

This patch fixes the installed command's next step to work without a source
checkout. The complete three action experience from 0.7.0 is included.

Three actions from the visual demo are now executable local experiments: sign in,
invoice payment and settings. Change an input, see validation block it, approve the
exact local action and inspect the state that changed. The experiment uses the
same artwork and cinematic visual language as the film.

## Try it

[Open the experiment](https://automatron-workflows.github.io/hardwire/experiment.html).
No app, account or API key is required.

With Node 22 or newer:

```sh
npx --yes --ignore-scripts --package=https://github.com/Automatron-workflows/hardwire/releases/download/v0.7.1/hardwire-0.7.1.tgz hardwire-experiment
```

The package comes from this GitHub release, not the unowned npm name `hardwire`.
The attached SHA256SUMS records its checksum. The release workflow verifies the
uploaded artifact by downloading and installing it in a fresh temporary project.

## Included

1. A cinematic browser experiment with explicit local consent and invoice approval.
2. The `hardwire-experiment` command covering all three fixtures and invalid requests.
3. Shared artwork, readable errors, reset and a keyboard accessible inspector.
4. The existing five inspection tools over local stdio MCP, portable core and CLI.
5. Community guidance and approachable contribution tasks on GitHub.

## Scope

Experimental release. Google sign in is a fixed fixture, not OAuth. Invoice
payment changes local state, not a balance. Local approval levels are assertions,
not verified identities. Compiled tools are descriptions; the toolkit MCP server
does not execute supplied actions. The film is not a speed benchmark.

npm and MCP Registry publication require a verified Automatron owned npm scope.
They are not part of this GitHub release.
