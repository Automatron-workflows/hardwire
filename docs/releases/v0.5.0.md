# Hardwire 0.5.0: a local MCP toolkit

Hardwire lets an agent inspect supplied HTML and action contracts through five
local MCP tools. No owned app, hosted server or API key is required. The source
is MIT licensed; npm publication remains a separate decision.

- Infer a draft panel from static HTML.
- Inspect declared effects and approval floors.
- Compile operations into MCP descriptions as data.
- Validate arguments against a declared port.
- Verify trace consistency and binding to a supplied panel.

Use Node 22+ (24 recommended). To try this exact release:

```sh
git clone --branch v0.5.0 --depth 1 https://github.com/Automatron-workflows/hardwire.git
cd hardwire
npm ci --ignore-scripts
npm run test:mcp
npm run --silent mcp:config
```

Merge the generated entry into your local MCP client's configuration. Follow
[the setup guide](https://github.com/Automatron-workflows/hardwire/blob/v0.5.0/docs/MCP.md)
for a first prompt and troubleshooting. No application ownership is needed.

Alternatively, download `hardwire-0.5.0.tgz` and `SHA256SUMS` from this release.
Verify with `shasum -a 256 -c SHA256SUMS` (macOS) or
`sha256sum --check SHA256SUMS` (Linux), then install it in a separate project:

```sh
npm install /absolute/path/to/hardwire-0.5.0.tgz --ignore-scripts
node node_modules/hardwire/scripts/client-config.mjs
```

The tarball is distributed through GitHub; no npm package or MCP Registry listing
is published. Do not use `npm install hardwire` to obtain this project.

Checks exercise an official MCP client, all handlers, rejected inputs, a tampered
trace, and the command from a clean package install. Existing unit/CLI and real
HTTP integration suites also run in CI on Node 22 and 24. The release workflow
downloads the uploaded artifact, verifies its checksum and repeats the installed
MCP check before the draft is published.

This is experimental inspection tooling. It does not browse sites, authenticate,
execute submitted ports or certify inferred effects. Trace digests are consistency
checks, not signatures or proof of execution. Existing 0.4.x panel/trace formats
are unchanged.
