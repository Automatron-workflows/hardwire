# Hardwire 0.8.1

Patch release for the 0.8 browser experiment and release pipeline.

- Fixes an accessibility defect in the experiment. Scenario tab state now
  applies only to the nav buttons, so the stage section no longer receives an
  unsupported `aria-pressed` attribute. An axe-core WCAG A/AA scan reports no
  violations after the fix; keyboard approval, Escape focus return and the
  390px layout were also checked.
- Refuses to reuse an existing version tag or GitHub release. Re-running the
  release workflow for a published version now fails before creating another
  draft.
- Corrects the specification's probe error name to `hardwire_origin_mismatch`
  and aligns the form experiment's documented output.

There are no panel, trace or public API changes. The `v0.8.0` tag and assets
remain immutable.

## Try it

Node 22 or newer:

```sh
npx --yes --ignore-scripts --package=https://github.com/Automatron-workflows/hardwire/releases/download/v0.8.1/hardwire-0.8.1.tgz hardwire-experiment
```

Or run the browser experiment:
https://automatron-workflows.github.io/hardwire/experiment.html

The fixtures are local. No account, payment provider, model or API key is
required. The package is not published on npm; `private: true` remains in
`package.json`.
